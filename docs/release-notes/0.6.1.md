AlbumCraft 0.6.1 brings the Linux packages back to older systems: they run on **Ubuntu 22.04, Debian 12 or newer** again, AI features included. Nothing else changes; Windows and macOS are the same as 0.6.0.

**Changes**
- The Linux packages (`.deb`, `.AppImage`, `.tar.gz`) need glibc 2.35 instead of 2.39. The Flatpak works everywhere, as before.
- On Linux, ONNX Runtime (which runs the networks of the AI features) is no longer built into the program: it comes as a file, `libonnxruntime.so`, inside each package. Without that file AlbumCraft still works, and *Settings → AI features* says that it is missing.

**Updating a `.tar.gz` copy**
- The built-in update replaces only the `albumcraft` program, so a `.tar.gz` copy updated from 0.6.0 has no `libonnxruntime.so` and its AI features stop. Download the `.tar.gz` again and unpack it over the old folder. The `.deb`, the AppImage and the Flatpak update themselves completely.

**Downloads**
- Windows x64: `albumcraft-0.6.1-windows-x64.msi` (installer) or `albumcraft-0.6.1-windows-x64-portable.zip`.
- Linux x86_64: `albumcraft-0.6.1-linux-x86_64.AppImage`, `.deb`, `.flatpak` or `.tar.gz`.
- macOS (Apple Silicon): `albumcraft-0.6.1-macos-arm64.dmg`.

These builds are not signed. On macOS, right-click the app and choose *Open* the first time. On Windows, choose *More info* → *Run anyway* in the SmartScreen prompt.

**Known limitations**
- Face recognition is not there yet.
- Moved pictures are analysed again for smart search.
- *Open with* lists no programs on macOS.
- The MCP tools, the system's own error messages and EXIF values stay in English. Right-to-left languages are not supported.
