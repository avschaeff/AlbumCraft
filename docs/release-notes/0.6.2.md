AlbumCraft 0.6.2 fixes the Linux AppImage on desktops that run X11 without Qt's keyboard library. Nothing else changes; Windows and macOS are the same as 0.6.0.

**Changes**
- The AppImage now carries `libxkbcommon-x11`, which the window needs under X11. Without it the window did not open on systems that don't have that library, which is common on GTK desktops (Cinnamon, Xfce, MATE).
- The `.deb` now recommends `libxkbcommon-x11-0`, so it is installed with AlbumCraft.

**Updating a `.tar.gz` copy**
- The `.tar.gz` uses the system's libraries. If AlbumCraft does not open under X11, install `libxkbcommon-x11-0` (Debian, Ubuntu) or `libxkbcommon-x11` (Fedora, Arch).
- A `.tar.gz` copy updated from 0.6.0 by the built-in update has no `libonnxruntime.so`, so its AI features stop. Download the `.tar.gz` again and unpack it over the old folder.

**Downloads**
- Windows x64: `albumcraft-0.6.2-windows-x64.msi` (installer) or `albumcraft-0.6.2-windows-x64-portable.zip`.
- Linux x86_64: `albumcraft-0.6.2-linux-x86_64.AppImage`, `.deb`, `.flatpak` or `.tar.gz` (Ubuntu 22.04, Debian 12 or newer).
- macOS (Apple Silicon): `albumcraft-0.6.2-macos-arm64.dmg`.

These builds are not signed. On macOS, right-click the app and choose *Open* the first time. On Windows, choose *More info* → *Run anyway* in the SmartScreen prompt.

**Known limitations**
- Face recognition is not there yet.
- Moved pictures are analysed again for smart search.
- *Open with* lists no programs on macOS.
- The MCP tools, the system's own error messages and EXIF values stay in English. Right-to-left languages are not supported.
