AlbumCraft 0.7 makes tags easier to manage, with a tag hierarchy and a tag manager. It also adds a Bright style, a folder tree that follows the disk, a choice of where the library file is kept, and a switch that turns the AI features off.

**New**
- **Tagging from the library's tags**: the Tags dialog and the editor's Tags section show the tags already in your library as chips, most used first and filtered as you type. A tick means all the selected pictures have that tag; a dash means only some do. Click a chip to put the tag on or take it off. The Tags dialog now applies changes at once.
- **Manage tags** (in the menu, the Tags dialog, the editor and the new Tags chip): the tag tree with counts. Rename a tag, merge it into another one, put it under another tag, create a group, show its pictures or delete it. Each change can be undone. A tag also finds the pictures of the tags under it, so *Buildings* finds *Church* and *Temple*.
- **Tags chip** in the top bar: the tag tree with totals. Click a tag to show its pictures.
- **Bright style** (*Settings → Interface → Style*): soft gradients on the bars, the sidebar and the selected row, and colour icons, in both light and dark mode. Calm, the familiar flat look, stays the default.
- **Folders as on disk**: the sidebar lists folders by year (as before) or as they are on disk, as one tree for each library folder with totals. Switch with the two buttons beside the Folders heading, or in *Settings → Folders*.
- **Library file location** (*Settings → Storage → Change folder…*): keep the library file in a folder you choose, for example next to your pictures. AlbumCraft never writes over a library that is already there; it offers to open that one instead. *Back to the default folder* moves the file back.
- **Turn the AI features off** (*Settings → AI features*): no network is loaded, nothing is analysed, and *Looks like*, *More like this* and tag proposals go away. Downloaded networks and stored results are kept for when you turn them back on.
- **MCP**: `list_tags` and `edit_tag` (rename or merge, parent, delete). `search_photos` with a `tag` also finds the pictures of the tags under it.

**Changes**
- Smart search uses one network, picked from a drop-down in *Settings → AI features*. Multilingual is the default whatever the interface language. You can remove a network you no longer use from the same place.
- *Same as system* now uses the light theme when the system does not report one.
- In narrow windows, the search box's chips are shortened so the box never covers the chips beside it.

**Downloads**
- Windows x64: `albumcraft-0.7.0-windows-x64.msi` (installer) or `albumcraft-0.7.0-windows-x64-portable.zip`.
- Linux x86_64: `albumcraft-0.7.0-linux-x86_64.AppImage`, `.deb`, `.flatpak` or `.tar.gz` (Ubuntu 22.04, Debian 12 or newer).
- macOS (Apple Silicon): `albumcraft-0.7.0-macos-arm64.dmg`.

These builds are not signed. On macOS, right-click the app and choose *Open* the first time. On Windows, choose *More info* → *Run anyway* in the SmartScreen prompt.

**Known limitations**
- Face recognition is not there yet.
- Moved pictures are analysed again for smart search.
- *Open with* lists no programs on macOS.
- A `.tar.gz` copy updated by the built-in update keeps its old `libonnxruntime.so`; a copy updated from 0.6.0 has none, so download the `.tar.gz` again and unpack it over the old folder.
- The MCP tools, the system's own error messages and EXIF values stay in English. Right-to-left languages are not supported.
- Video files are not shown or imported.
- Printing doesn't work in the Flatpak yet. Use the `.deb` or the AppImage to print on Linux.
- Raw files are not developed from sensor data; edits work on the embedded preview.
